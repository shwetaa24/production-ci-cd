# 🛠️ Professional Flask DevSecOps Pipeline

This repository provides a production-ready CI/CD template using GitHub Actions, Docker, and Security Best Practices.

## ✨ Features
- **Automated Testing:** Runs `pytest` on every push.
- **Linting:** Ensures PEP8 compliance with `flake8`.
- **Security First:** Built-in **Trivy** vulnerability scanning.
- **Production Grade:** Optimized Dockerfile using a non-root user.

## 📦 What's Included
- Complete GitHub Actions Workflow
- Production-ready Dockerfile
- Step-by-step Setup Guide
